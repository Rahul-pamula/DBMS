# Assignment 1: Environment Setup

Welcome to the DBMS course! Before we start writing SQL, we need to set up our tools and learn how to collaborate using GitHub.

## Tasks
1. **Install Antigravity IDE:** Download and install the Antigravity IDE on your computer.
2. **Install Git:** Make sure you have Git installed and configured on your terminal.
3. **Clone this repository:** Clone the class repository to your local machine.

## How to submit your assignment
1. Open Antigravity IDE.
2. Take a screenshot of the Antigravity home page.
3. Save the image in this folder (`assignments/assignment-1/`) with your name (e.g., `yamini_screenshot.png`).
4. Create a new markdown file with your name (e.g., `yamini.md`) in this folder.
5. Inside your markdown file, embed your screenshot using standard markdown formatting: `![My Setup](yamini_screenshot.png)`.
6. Create a new Git branch.
7. Commit your markdown file and image, then push your branch to GitHub.
8. Open a Pull Request (PR) against the `main` branch to complete the assignment!

> [!TIP]
> **Need help?** Don't be afraid to use **Antigravity** or **ChatGPT**! If you get stuck on Git commands or how to format Markdown, ask your AI assistant to guide you through the process.
