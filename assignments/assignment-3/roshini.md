DDL (Data Definition Language)* is a category of SQL commands used to define and manage the structure of database objects such as databases and tables. DDL commands help create, modify, rename, truncate, and delete tables. These commands change the database schema permanently.

### Common DDL Commands

- *CREATE* – Creates a new database or table.
- *ALTER* – Modifies the structure of an existing table.
- *ADD* – Adds a new column to a table.
- *MODIFY* – Changes the data type or size of an existing column.
- *DROP* – Deletes a table or a column permanently.
- *TRUNCATE* – Removes all records from a table but keeps its structure.
- *RENAME* – Changes the name of a table or column.

*Conclusion:*  
DDL commands are essential for designing and managing the structure of a database. They allow users to create, update, and maintain database objects efficiently.
