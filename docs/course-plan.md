# DBMS Course Plan

## Unit 1 – Introduction (10%)
Goal: Build a strong conceptual foundation before writing any SQL.
1. Characteristics of Database Approach
2. Database Models
3. DBMS Architecture
4. Data Independence
5. Database Users
6. Database Administrator (DBA)
7. Key Concepts of DBMS

## Unit 2 – SQL & PL/SQL Concepts (30%)
This is where coding starts.
1. Introduction to SQL
2. DDL (CREATE, ALTER, DROP, TRUNCATE)
3. DML (INSERT, UPDATE, DELETE)
4. DCL (GRANT, REVOKE)
5. Constraints (Primary Key, Foreign Key, Unique, Not Null, Check, Default)
6. Functions (Aggregate Functions, Built-in Functions: Numeric, String, Date)
7. Set Operations
8. Subqueries & Nested Subqueries
9. GROUP BY, HAVING, ORDER BY
10. JOINS
11. Views
12. Transaction Control (COMMIT, ROLLBACK, SAVEPOINT)
13. PL/SQL Basics, Cursors
14. Stored Procedures & Stored Functions
15. Database Triggers

## Unit 3 – Relational Model
* Structure of Relational Database
* Codd's Rules
* Domains, Relations
* Schema & Instance
* Relational Algebra
* Tuple Relational Calculus

## Unit 4 – Entity Relationship Model
* Introduction & Design Process
* Constraints, Keys, Design Issues
* ER Diagrams
* Weak Entity Sets
* Generalization, Specialization, Aggregation

## Unit 5 – Relational Database Design
* Functional Dependency (Trivial & Non-trivial FD, Closure of FD, Closure of Attributes, Irreducible Set)
* 1NF, 2NF, 3NF, BCNF
* Multivalued Dependency (4NF)
* Join Dependency (5NF)

## Unit 6 – Transaction Management
* Transaction Concepts & ACID Properties
* Serializability
* System Recovery (Two-Phase Commit, Atomicity, Log-Based Recovery)
* Concurrent Transactions (Locking Mechanism, Deadlock, Two-Phase Locking, Isolation, Intent Locking)
